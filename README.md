# Control

Платформа для централизованного управления умным домом

## Технологии

- Java, Spring Boot
- PostgreSQL 16
- Apache Kafka + Zookeeper
- Docker + Docker Compose
- Kubernetes (Minikube) + Helm
- Prometheus + Grafana

## Функциональность

### Ручное управление

- Батареи: установка и просмотр температуры
- Жалюзи: открыть, закрыть, установить процент открытия
- Расписание: создание задач по времени

### Автоматическое управление (погода)

Каждые 10 минут система получает погоду с OpenWeatherMap и применяет правила:

- Холодно (< 10°C) → повысить температуру батарей до 24°C
- Жарко (> 25°C) → снизить температуру батарей до 0°C
- Солнечно (clear sky / sun) → закрыть жалюзи

### Асинхронная обработка

- Все действия пользователя и погодной автоматики отправляются в Kafka
- Логи сохраняются в БД асинхронно

### Мониторинг

- Prometheus для сбор метрик
- Grafana для визуализации (JVM, HTTP, Kafka)
- Actuator: health, prometheus, metrics
